# Database Programming

## Introduction
This subject combines SQL development with application-level database usage. The work includes DDL, DML, DQL, indexing, and an event booking system implementation.

### Core Focal Points
* Designing and updating databases through SQL scripts.
* Applying DDL, DML, DQL, and indexing in a structured workflow.
* Linking database logic with a practical application script.
