# Operating System

## Introduction
This subject introduces core operating system concepts through labs and coding practice. The materials combine theory with a small implementation project in C++.

### Core Focal Points
* Understanding how operating systems support system-level behavior.
* Practicing through lab-based exercises.
* Applying concepts in a small implementation project.
