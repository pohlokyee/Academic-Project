# Object-Oriented Programming

## Introduction
This subject teaches OOP concepts such as classes, objects, inheritance, and code organization. The perfume system project applies these ideas in a Java application.

### Core Focal Points
* Designing software with classes and objects.
* Applying inheritance and structured code flow.
* Building reusable Java code.
