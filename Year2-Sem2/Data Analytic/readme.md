# Data Analytic

## Introduction
This subject focuses on analyzing data using notebook-based workflows. The assignments and full project include data preparation, analysis, and presenting useful insights.

### Core Focal Points
* Preparing data for analysis.
* Using notebooks to explore and summarize results.
* Presenting insights in a clear and structured way.
