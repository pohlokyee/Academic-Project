# Academic Projects Portfolio | Year 3 Semester 2

## Introduction
Welcome to my academic project portfolio for Year 3, Semester 2. This semester has focused heavily on scaling technical foundational skills, mastering modern data engineering frameworks, and translating raw data architectures into strategic corporate business intelligence. 

The curriculum is anchored around three primary, advanced core subjects:
1. **Business Intelligence:** Concentrating on the end-to-end data analytics lifecycle, data transformation via Alteryx, and strategic enterprise dashboard implementation.
2. **High Performance Data Processing:** Focusing on parallel computing structures, high-performance computing (HPC) frameworks, and cloud-scale data engineering platform optimization.
3. **Special Topic in Data Engineering:** Deepening core data engineering architecture insights, industrial workflows, and the implementation of robust enterprise pipeline designs.
