# Software Engineering

## Introduction
This subject covers software project planning and documentation, including proposal writing and requirement and design documents. It focuses on how a project moves from an idea into structured development.

### Core Focal Points
* Software planning and proposal development.
* Requirements, design, and technical documentation.
* Organizing work from concept to delivery.
