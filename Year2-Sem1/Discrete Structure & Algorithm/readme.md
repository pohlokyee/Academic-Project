# Discrete Structure & Algorithm

## Introduction
This subject focuses on logic, problem solving, and algorithm thinking. Through C++ coding, assignments, and labs, it practices building solutions using data structures and clear algorithm steps.

### Core Focal Points
* Logical reasoning and algorithm design.
* C++ implementation for structured problem solving.
* Practice through assignments, labs, and simulation work.
