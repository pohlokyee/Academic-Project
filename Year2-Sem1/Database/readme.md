# Database

## Introduction
This subject introduces the basic ideas of databases, including storing data in tables, designing relationships, and writing structured queries. The assignments and reports show how to plan and explain a database solution step by step.

### Core Focal Points
* Relational data design and table structure.
* Structured problem solving through assignments and reports.
* Clear technical documentation for database work.
