# Academic Projects Portfolio | Year 2 Semester 1

## Introduction
Welcome to my academic project portfolio for Year 2, Semester 1. This semester built the core computing foundation through database design, algorithmic problem solving, network communication analysis, and software engineering documentation.

The semester is centered around four core subjects:
1. **Database:** Learning how to structure data, explain solutions, and document database work clearly.
2. **Discrete Structure & Algorithm:** Practicing logic, C++ implementation, and simulation-based problem solving.
3. **Network Communication:** Studying packet-level communication through lab traces and protocol analysis.
4. **Software Engineering:** Understanding project planning, requirements, and structured documentation.
