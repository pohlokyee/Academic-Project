# Network Communication

## Introduction
This subject introduces how computers communicate in a network. The lab files and packet traces cover DNS, HTTP, TCP/UDP, and ARP through hands-on analysis.

### Core Focal Points
* Understanding how core network protocols work.
* Reading packet captures and observing communication flow.
* Learning protocol behavior through practical labs.
